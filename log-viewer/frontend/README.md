# Log viewer frontend

React + Vite frontend for browsing the MariaDB-backed request and pipeline logs generated by the bot.

## What this app is for

| Feature | What it gives you |
| --- | --- |
| Login flow | Authenticated access to logs |
| Log list | Recent API/pipeline activity |
| Log detail pages | Deeper inspection of requests, responses, and replay artifacts |
| Realtime updates | New logs streamed over Socket.IO |
| Media helpers | Backend-proxied media loading to avoid CORS pain |

## Stack

| Layer | Tech |
| --- | --- |
| UI | React 19 |
| Routing | React Router |
| Build/dev server | Vite |
| Language | TypeScript |
| Styling | Tailwind CSS |
| Data fetching | Axios |
| Realtime | Socket.IO client |
| Tests | Vitest |

## Environment variables

| Variable | Default | Used for |
| --- | --- | --- |
| `VITE_PORT` | `5173` | Dev server port |
| `VITE_PREVIEW_PORT` | `4173` | Preview port |
| `VITE_API_URL` | `/api` | HTTP calls for login, logs, details, and proxy-media helpers |
| `VITE_SOCKET_URL` | `/` | Socket.IO connection target |
| `VITE_BACKEND_PROXY_TARGET` | `http://backend:3001` | Vite dev proxy target |
| `VITE_DISCORD_GUILD_ID` | fallback demo guild ID in frontend utility code | Discord-related UI parsing helpers |

## Development modes

### Preferred in this repo: run with Docker

```bash
docker compose --env-file .env.development up --build frontend backend db
```

This gives you the frontend together with the backend and MariaDB it expects.

### Standalone frontend iteration

If you run the frontend outside Docker, make sure the backend is reachable and set at least:

```bash
VITE_API_URL=/api
VITE_SOCKET_URL=/
VITE_BACKEND_PROXY_TARGET=http://localhost:3001
```

## What the frontend expects from the backend

| Backend capability | Why the frontend needs it |
| --- | --- |
| `POST /api/login` | Authenticate and receive JWT |
| `GET /api/logs` | Render the main log list |
| `GET /api/logs/:id` | Render detail pages |
| media proxy routes under `/api` | Load remote media through the backend |
| Socket.IO auth + events | Realtime log streaming |
